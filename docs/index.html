Why QCKit
告别传统 QC 工具的三大痛点

😩 传统方式

  • 每次 QCC 都在填一样的 Excel 空白格子
  • 关联图、鱼骨图要手工在 Visio 里连线
  • 汇报要 PPT，只能截 Excel 图片
  • 老板问「为啥选这几条要因」答不上来
  • 企业品牌颜色手工调，导出物风格不统一

🚀 用 QCKit 之后

  • 输入课题 → AI 分析末端要因、给出推理
  • Cytoscape/SVG 交互图，鼠标拖拽即调
  • PPTX 导出 = 原生形状，PPT 里继续编辑
  • 每条判定都附 LLM 推理依据，可追溯
  • 品牌主题一次设置，全站导出自动应用

Quick Start
3 步跑起来
Docker / 本地 Python / 一体化打包 · 任选
1

Clone 仓库

从 GitHub 拉下代码到本地

git clone https://github.com/yidingwanglnsy-boop/qckit.git cd qckit
2

启动服务

用 Docker Compose 一键起

docker compose up -d
3

接入 AI

浏览器打开 http://localhost:8000，在「大模型 API」向导里 3 步配好 Key

推荐先用阿里百炼 新用户额度多、无需信用卡
